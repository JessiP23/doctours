Every judgment call made where the brief was unclear, in the order it was made. Feeds the product video.

| 1   | Day 1 | Put a `TravelProvider` adapter between the agent tools and Sabre.                                                                                                                                     | The brief uses offer/order vocabulary ("Sabre Flights / Stays", "offers expire", "real order with a booking reference") that doesn't map 1:1 onto Sabre's classic REST flow (Bargain Finder Max → Create PNR; Get Hotel Avail → Price Check → Enhanced Hotel Book). Isolating the provider means the agent, DB and UI are written once against normalized types. Also makes L3 "any origin/destination" cheap. | Calling Sabre directly from tools (fast to start, expensive to change). |
| 2   | Day 1 | Custom agent loop on `@anthropic-ai/sdk`, not Vercel AI SDK.                                                                                                                                          | Brief forbids streaming and wants short, human, multi-bubble replies.
